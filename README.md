# IoT-Gas-Leakage-Monitoring-System
Smart Gas Leakage Monitoring and Alarm System using Arduino, ESP-01, MQTT, and Node-RED.

## 📂 Repository Structure
- `Arduino/`: Contains the C++ source code for Arduino Uno & ESP-01.
- `Node-RED/`: Contains the exported JSON flow configuration for Node-RED dashboard and alert nodes.
- `Images/`: Contains project hardware setup and live dashboard screenshots.

## 🚀 Technologies Used
- Hardware: Arduino Uno, ESP-01 WiFi Module, MQ Gas Sensor, Buzzer, Dual Lithium-ion Batteries.
- Protocols & Software: MQTT (Mosquitto Broker), Node-RED, Arduino IDE (C++).
